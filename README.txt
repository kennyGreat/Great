SETUP
-----
1. Extract all files keeping the folder structure
2. Open index.html in a web browser
3. To customize, edit the HTML files and CSS

CUSTOMIZATION
-------------
• Colors: Edit the CSS variables in :root at the top of style.css
• Content: Edit the HTML files directly
• Images: Add your images to assets/images/ and update HTML
• Phone/Email: Update contact info across all HTML files
